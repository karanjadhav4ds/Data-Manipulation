# Data Manipulation Using NumPy & Pandas

## Overview
This project demonstrates data cleaning, preprocessing, and manipulation using Python, NumPy, and Pandas in Jupyter Notebook. Using retail transaction data, the project explores how raw data can be transformed into a structured format for further analysis.

## Key Features
- Dataset inspection and exploratory data checks
- Missing-value analysis and handling
- Duplicate detection and removal
- Data type conversion and standardization
- Feature engineering and revenue calculations
- Data filtering, sorting, grouping, and aggregation
- MultiIndex-based summaries
- Exporting processed data and summaries to CSV

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Skills Demonstrated
Data Cleaning, Data Manipulation, Data Preprocessing, Feature Engineering, Data Transformation, and Data Aggregation.

## Project Purpose
The purpose of this project is to build practical skills in preparing raw datasets for analysis and developing a structured data-cleaning workflow.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Place the required dataset in the appropriate location.
5. Run the notebook cells in sequence.
